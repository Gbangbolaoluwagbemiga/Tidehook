# TideHook Scripting & Testing Guide (For Judges) 🌊

This guide provides hackathon judges with the exact steps to deploy, test, and verify the TideHook protocol on the **Unichain Sepolia** testnet.

---

## 🛠️ Prerequisites

1. **Foundry installed**: `curl -L https://foundry.paradigm.xyz | bash`
2. **Environment Variables**: Create a `.env` file in the root directory (copy the template below).
3. **Testnet Assets**: Ensure your deployer address has Unichain Sepolia ETH (available via the [Unichain Faucet](https://www.unichain.org/faucet)).

### `.env` Template
```bash
PRIVATE_KEY=your_private_key
RPC_URL_UNICHENT_SEPOLIA=https://sepolia.unichain.org
# Optional: The following will be auto-generated by the E2E script
TIDE_HOOK=...
POOL_MANAGER=...
USDC_ADDRESS=...
ETH_ADDRESS=...
POOL_MODIFY_LIQUIDITY_TEST=...
```

---

## 🚀 1. Full Protocol Deployment (E2E)

To deploy the entire stack (Mock Tokens, Uniswap v4 PoolManager, TideHook, and initialized V4 Pools), run:

```bash
source .env && forge script script/DeployE2E.s.sol \
  --rpc-url $RPC_URL_UNICHENT_SEPOLIA \
  --broadcast \
  --chain-id 1301 \
  --gas-price 3000000 \
  --slow
```

**What this does:**
1. Deploys `PoolManager` (v4 core).
2. Deploys `MockUSDC` and `MockETH`.
3. Deploys `TideHook` with a pre-mined address (required for v4 hooks).
4. Initializes a **USDC/ETH Pool** with TideHook enabled.
5. Adds initial liquidity to the pool.

---

## 🐋 2. Testing the Whale Auction (E2E Flow)

TideHook automatically intercepts large trades. To test this:

### Step A: Trigger via UI
1. Navigate to the **Swap** page in the frontend.
2. Ensure you are connected to the deployer wallet.
3. Use the **Faucet** button to get Mock USDC.
4. Input a large amount (e.g., **15,000,000 USDC**).
5. The UI will classify this as a **"WHALE TRADE"**.
6. Click **Approve** and then **Initiate Auction**.

### Step B: Manual Settlement (Simulation)
While the **Reactive Network** automatically ticks auctions every few blocks, you can manually force an auction to advance/settle for testing purposes:

```bash
source .env && forge script script/TickAuction.s.sol \
  --rpc-url $RPC_URL_UNICHENT_SEPOLIA \
  --broadcast
```

## 📊 3. Verification & Analytics

Once an auction is initiated or settled, you can verify the results on the **Analytics** page:

1. **Trade Classification**: Verify that retail trades moved the price instantly, while whale trades were successfully smoothed.
2. **On-Chain Logs**: All actions emit `WhaleAuctionStarted` and `WhaleAuctionCompleted` events.
3. **Dutch Math**: Observe the real-time block countdown and linear price decay in the Auction Card.

## 🛠️ Utility Scripts Reference

| Script | Purpose |
|---|---|
| `DeployE2E.s.sol` | Full protocol setup (Tokens + Hook + Pool + Liquidity) |
| `TickAuction.s.sol` | Manually advance/settle the active Dutch Auction |
| `RefillPool.s.sol` | Emergency liquidity injection if the pool becomes depleted |
| `DebugPool.s.sol` | Query the current `slot0` price and reserves of the v4 pool |
| `VerifyFlow.s.sol` | Performs a programmatic retail swap followed by a whale swap |
